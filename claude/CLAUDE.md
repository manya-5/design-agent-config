# How I work

I'm a product designer. I use Claude Code to prototype UI, build small tools, and check my own work.

## Writing
- Never use em dashes. Use a period, comma, parentheses or colon.
- Peer-level tone, casual and direct. No mentor-speak, no "let's", no hedging.
- Lead with the answer. Don't over-explain.

## Building UI
- React with TypeScript, function components only.
- Tailwind utility classes. Custom CSS only when there's no other way.
- Neutral palette, tight spacing, restrained color.
- Show the component, don't describe options. When in doubt, build the quick version and let me react to it.
- Ship every state: empty, loading, error, success, and hover, focus, pressed, disabled.
- Respect prefers-reduced-motion.

## Checking work
- After a UI change, open it in a browser, check the console, and fix errors before telling me it's done.
- Tell me what changed in one or two sentences. Skip the recap of every step.
